# IT Skills Taxonomy — Master List for Job Matching

**Purpose:** Filter, tag, and match scraped job postings against this master list of IT skills/technologies. Used by the sourcing agent when parsing `sourced-requirements/` and new scraped jobs.
**Last updated:** 2026-08-01 (seeded from 2026-07-13 nvoids.com scrape, 100 jobs)

---

## How to use
- Match postings against the **Skill + Aliases** columns. If a posting mentions an alias, tag it with the canonical skill.
- The **Domain** keywords are optional filters (banking, pharma, insurance, etc.) used to narrow matches.
- **High-demand now** = skills that appeared most in the current scrape — prioritize matching those first.
